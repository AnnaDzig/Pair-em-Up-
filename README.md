**Pair ’em Up** is a browser-based number puzzle game inspired by classic number-matching logic games.

The player removes pairs of numbers from a squared math notebook board. A pair can be removed when the numbers are either the same or their sum equals 10. Numbers must also be connected horizontally, vertically, or in reading order across lines, with only empty cells between them.

The Classic mode starts with a fixed number layout and gives the player 10 Add Numbers tries. Each try adds all numbers that are still visible on the board, in reading order. The player wins only when every number has been removed.

The game includes a clean handwritten notebook design, blue pen-style numbers, visible empty cells after removal, a timer, hints, undo, save/continue functionality, and different game modes for extra challenge.
